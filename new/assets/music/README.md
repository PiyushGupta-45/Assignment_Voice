# Background music assets

Place only music you own or have a license to use and redistribute in the style folders. Supported formats: MP3, WAV, AAC, FLAC, M4A, OGG. The service loops the selected instrumental and trims output to the voice duration.

Add at least one track for every style you expose (or add a `default/` folder with a fallback track). No audio assets are included in this repository.
